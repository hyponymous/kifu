# kifu

**[hyponymous.github.io/kifu](https://hyponymous.github.io/kifu/)**

Share SGF game files via URL — no server, no storage.

SGF data is compressed and encoded directly into the URL fragment (`#…`), which is never sent to the server. Anyone with the link can download the file; nothing is stored anywhere.

## Usage

**Sharing a file:** paste SGF or drop a file on the page to get a shareable link.

**Receiving a file:** open the link — the file is decoded in the browser and offered as a download.
